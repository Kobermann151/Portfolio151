# Portfolio Website

A simple personal portfolio landing page built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Customize

Update the text in [index.html](index.html) to add your own name, bio, projects, and contact details.
